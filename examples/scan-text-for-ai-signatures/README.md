The `signature` package on its own: commit messages, pull-request descriptions and review comments scanned for the footers and trailers AI coding tools leave. A header that claims AI authorship without naming a known tool counts as `ai-unknown`. It needs only the text.

```sh
go run ./examples/scan-text-for-ai-signatures
```

```text
commit        "Co-authored-by: Claude <noreply@anthropic.com>" true  [claude-code]
commit        "Co-authored-by: Jane Doe <jane@example.com>"    false []
pull request  "Generated by Copilot"                           true  [copilot]
pull request  "Tested by hand."                                false []
review        "## Kiro AI Review"                              true  [kiro]
review        "Reviewer: Someothertool AI"                     true  [ai-unknown]
review        "Looks good to me."                              false []

merged: true [claude-code copilot]
```
