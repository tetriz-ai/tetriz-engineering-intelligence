Scores four weekly readings of the code stage, stores each week's cells and bottlenecks the way a caller would, and derives the movement series with `DeriveMovement`. Code L1 reads emerging in the second week and established in the third. It is reported as moved up in the fourth week, starting 2026-03-23, once established has held for two weeks. It then reads the deployment's adoption state with `ResolveAdoptionState`: 14 active engineers against 10 the month before is growth.

```sh
go run ./examples/track-movement
```
