# Security policy

## Reporting a vulnerability

Report a vulnerability privately, through this repository's **Security** tab → **Report a
vulnerability**. That opens a private advisory only the maintainers can read.

Please do not open a public issue or pull request for a vulnerability, and please do not post
details anywhere public until a fix is out.

What helps most, and none of it is required:

- what the problem is, and what an attacker gets from it;
- the smallest input, call or program that shows it;
- which packages and which version or commit you were on.

You will get a reply. We have not been running this long enough to promise how fast, so we are not
going to invent a number.

## What is in scope

The Go packages in this repository, and the example programs. A vulnerability in a dependency
belongs to that project; tell us anyway if this repository's use of it is what makes it reachable.
